About Me

Analytical Thinker, Data-Driven Builder

I'm Joalnes John D. Vender, a BS Computer Science student with a strong focus on data analytics, database management, and business intelligence. My foundation spans statistical thinking, database systems, and software engineering—skills I apply through hands-on projects and industry-recognized certifications.

I work across the data lifecycle: cleaning and analyzing data, writing SQL queries for relational databases, developing web-based analytics interfaces with HTML, CSS, and JavaScript, and building mobile solutions with Flutter. I use Python and Java for backend logic and data processing, and Git & GitHub for version control and collaboration. Every insight I uncover is communicated through clear, actionable visualizations.

Beyond the technical stack, I care about solving real problems. My work on OnlyFunds—a budget tracking application—showed me how thoughtful data design can improve day-to-day financial decisions. I bring that same user-centered, evidence-based mindset to every project I take on.
